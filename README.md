# Query Masters - Group 4 Python Quests

## Project Overview

This repository contains our solutions for the **Python Basics - Peer Group Reviewed Activity**.

The goal of this project is to strengthen our understanding of Python fundamentals through practical coding quests covering:

- Variables and Printing
- User Input and Basic Math
- Conditional Statements
- Loops
- Functions
- Grand Challenges

Our group is required to complete at least **4 tasks from each of the 6 levels**, giving us a minimum of **24 completed quests**.
